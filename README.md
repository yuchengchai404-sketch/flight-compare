## 当前状态

这是公开的开发源码快照，不是已经全面验收的商业服务。**国际航线部分流程已实测，国内航线尚未完整适配，请勿当作国内航班比价工具使用。**

- Google Flights：去程、回程分别查询单程。
- 携程：国际单程可见页面采集，展开已加载航班的票价明细。
- 同程：国际单程及部分完整往返页面适配。
- 飞猪、途牛：包含接口适配代码，需要使用者自行获得有效授权；不附带可用凭据，不保证所有航线或账户均可用。
- 浏览器助手版本：0.6.10。只采集已确认直飞的记录，不采集中转及无法确认直飞的记录。
- 带年龄限制的票价不参与排名；其他资格、币种、舱位或价格证据不足的记录保留待核验。
- 价格按官网起价展示，明确区分单程、完整往返和两张单程合计。¥/￥默认人民币，明确标注的外币不按人民币处理。
- 页面采集只覆盖已加载并可识别的报价，不保证覆盖全部库存。官网变化可能使适配失效。

## 工作流程

设置行程 → 获取各平台报价 → 比较结果。浏览器助手由用户在官网手动触发，读取可见报价后回传自己的工作台。登录和验证码由用户本人完成。软件不创建订单、不进入支付流程。

## 开发与部署

技术栈：TypeScript、React、Next.js/vinext、Cloudflare D1，以及 Chrome Manifest V3 扩展。

1. 安装 Node.js 22.13 或以上版本，执行 `npm ci`。
2. 将 `.openai/hosting.example.json` 复制为 `.openai/hosting.json`，配置自己的托管环境；仓库没有原部署的项目标识。
3. 按 `.env.example` 配置自己的服务端环境变量，不要提交真实密钥。
4. 执行 `npm run dev` 进行本地开发。运行环境依赖原有 Sites/Cloudflare 绑定；本仓库不是任意服务器上一键部署的独立发行版。
5. 部署前把扩展和测试中 `flight-compare.example.com` 占位域名替换为自己的 HTTPS 域名。检查 `browser-helper/manifest.json` 和 `background.js`，仅允许自己的接收端。
6. 执行 `node scripts/pack-browser-helper.mjs` 生成扩展包，在浏览器扩展管理页加载解压后的 `browser-helper` 文件夹。

**鉴权边界：**当前应用依赖受信任的 Sites 入口注入身份请求头。不要直接把开发服务器或可伪造身份头的后端暴露到公网。迁移到其他托管环境前，必须实现服务端身份验证、访问控制和密钥管理；开发环境模拟登录不适合生产。

## 检查

运行 `node scripts/test-*.mjs` 中的各个脚本（逐个执行文件，通配符需由脚本或终端展开），以及 `npx tsc --noEmit --incremental false`。页面结构和动态库存必须另外进行真实页面核对；单元测试通过不代表所有平台、航线和日期均可用。

测试目录包含用于解析回归的页面文字样例，它们不是当前可购买报价。生产历史报价、账户授权、数据库、日志、原站点标识和旧 Git 历史均不随此快照发布。
