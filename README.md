## 工作流程

设置行程 → 获取各平台报价 → 比较结果。一键获取会打开官网去返程查询，等待可识别结果稳定后自动采集直飞报价并回传自己的工作台。登录、验证或超时会暂停该项并在工作台提示处理，其他任务继续；也保留手动重试入口。自动模式不会操作验证码、登录表单或购买流程。登录和验证码由用户本人完成。软件不创建订单、不进入支付流程。

## 开发与部署

技术栈：TypeScript、React、Next.js/vinext、Cloudflare D1，以及 Chrome Manifest V3 扩展。

1. 安装 Node.js 22.13 或以上版本，执行 `npm ci`。
2. 将 `.openai/hosting.example.json` 复制为 `.openai/hosting.json`，配置自己的托管环境；仓库没有原部署的项目标识。
3. 按 `.env.example` 配置自己的服务端环境变量，不要提交真实密钥。
4. 执行 `npm run dev` 进行本地开发。运行环境依赖原有 Sites/Cloudflare 绑定；本仓库不是任意服务器上一键部署的独立发行版。
5. 部署前把扩展和测试中 `flight-compare.example.com` 占位域名替换为自己的 HTTPS 域名。检查 `browser-helper/manifest.json` 和 `background.js`，仅允许自己的接收端。
6. 执行 `node scripts/pack-browser-helper.mjs` 生成扩展包，在浏览器扩展管理页加载解压后的 `browser-helper` 文件夹。

**鉴权边界：**当前应用依赖受信任的 Sites 入口注入身份请求头。不要直接把开发服务器或可伪造身份头的后端暴露到公网。迁移到其他托管环境前，必须实现服务端身份验证、访问控制和密钥管理；开发环境模拟登录不适合生产。

支持23个主要国内城市：上海、北京、广州、深圳、成都、杭州、重庆、西安、武汉、南京、厦门、长沙、青岛、昆明、三亚、海口、郑州、济南、大连、沈阳、哈尔滨、天津、福州。上海、北京、成都均保留多机场范围。

国内和国际入口已分开；同程国内目前支持1位成人经济舱，按去程、回程分别读取。飞猪、途牛国内查询提供两张单程合计；只收录确认直飞且无年龄、身份限制的有效报价，接口返回仍是部分库存。

## 2026-10-30 自动流程验收（助手 0.6.24）

上海—重庆，2026-12-19 去程、12-21 回程，1位成人经济舱、仅直飞：Google Flights、携程、同程、飞猪的8项官网采集完成，途牛本轮去返程接口完成。平台显示“五平台已全部完成”。飞猪回程触发官网滑块，由本人验证后点击“已处理，继续”，后续读取和回传自动完成，没有人工填入或伪造报价。

飞猪官网本轮去程50条、回程55条进入比较。抽查9C6107去程：票价300元＋页面机建燃油140元＝440元；9C6108回程：270元＋140元＝410元。回程原有10条旧接口快照不再混入当前官网模式的结果，避免同航班新旧记录重复及税费口径混淆。

这是上述条件下的流程与样本价格验证，不代表所有城市、日期、舱位、全部库存或长期稳定性均已验收。途牛仍只核验首批最低直飞候选，不能声称全网最低。含税价与税费未明确起价保持标记；它们不是相同支付总价口径。内置浏览器控制仍观察到延迟和旧标签绑定故障，实际使用需保持查询窗口可见。
